# ✊ Pedra, Papel e Tesoura - Mão Animada

Jogo em Python com animação de mão humana feito para a AP2 de Algoritmo e Lógica II.

## 🎮 Como funciona
A mão do PC faz a animação JO-KEN-PO:
- ✊ Pedra = mão fechada
- 🖐️ Papel = mão aberta  
- ✌️ Tesoura = 2 dedos em V

## 🚀 Como jogar
```bash
python jogo_mao_animada.py
